# Anime Bazar

This project focuses on enhancing the navigation bar of the **Anime Bazar** website using Bootstrap and custom CSS. The navbar has been transformed into an offcanvas menu for better user experience on mobile and smaller screens.

## Features

- **Responsive Navbar**: The navbar adapts to different screen sizes and uses an offcanvas menu to improve navigation.
- **Hover Effects**: Smooth hover effects with color transitions for a visually appealing experience.
- **Custom Theme Color**: Utilizes a theme color defined in CSS for a consistent design across the site.
- **Search Functionality**: Integrated search bar with a sleek design.

## Technologies Used

- **HTML5**
- **CSS3**
- **Bootstrap 5.3**

## Code Enhancements

1. **Offcanvas Navbar**: Replaced the default navbar with a collapsible offcanvas menu to enhance mobile usability.
2. **Custom CSS**:
   - Added hover effects for navbar links.
   - Customized the search bar and button with theme colors.
   - Styled the brand name for better visibility.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/MBSciTech/SEM3_GP-fsd-
   ```

2. Open `index.html` in your preferred browser to view the project.

## Usage

- Open the menu by clicking the hamburger icon.
- Use the search bar to look for items.
- Hover over the links to see the color transitions.
